# YOLOX Results Notes

- YOLOX was tested as an alternative object detection model
- The model successfully detected vehicles and pedestrians in urban scenes
- Detection performance was comparable to YOLOv7 in most cases
- The anchor-free design simplifies the detection process

However, the setup required additional configuration compared to YOLOv7, which may affect deployment ease.

This experiment was included to compare different detection approaches for ADAS perception.
